# Руководство пользователя

## Запуск

```bash
kuznica                 # обычный запуск
kuznica program.deb     # сразу открыть пакет
kuznica -version        # версия
```

## Главное окно

| Элемент | Назначение |
| --- | --- |
| Меню «Файл» | открыть пакет, выход |
| Меню «Правка» | копировать журнал в буфер, очистить журнал |
| Меню «Настройки» | параметры программы |
| Меню «Справка» | «О программе» |
| Зона Drag & Drop | перетащите сюда `.deb` |
| Вкладка «Информация» | название, версия, архитектура, описание, размер, лицензия, автор, сайт, конфликты, рекомендации, число контрольных сумм |
| Вкладка «Зависимости» | список `Debian → Arch` |
| Вкладка «Файлы» | содержимое `data.tar` |
| Вкладка «Журнал» | все действия и ошибки |
| Кнопки | Конвертировать, Создать пакет, Установить, Открыть папку, Просмотреть журнал |

## Настройки

**Общие**

* Тема: системная, светлая, тёмная.
* Язык: русский, английский (интерфейс перестраивается сразу).
* Каталог сборки (по умолчанию `~/kuznica`).

**Работа**

* Использовать `makepkg` — если выключено, создаются только `PKGBUILD`/`.SRCINFO`.
* Удалять временные файлы.
* Автоматически устанавливать зависимости (`pacman -S --needed`).
* Создавать `.desktop`.
* Проверять `.desktop` через `desktop-file-validate`.
* Искать иконки автоматически.
* Показывать журнал после сборки.

Настройки хранятся в `~/.config/kuznica/config.json`.

## Файл .desktop

После конвертации, если включена настройка «Создавать .desktop»:

* если пакет уже содержит `.desktop`, программа спросит — использовать
  существующий, заменить, создать новый или открыть редактор;
* иначе создаётся новый файл: исполняемый файл ищется в `usr/bin`, `usr/sbin`,
  `opt`, иконка — в `usr/share/icons` и `usr/share/pixmaps`, категория
  выводится из секции Debian (`devel` → `Development;`, `games` → `Game;` …);
* в редакторе можно изменить `Name`, `Comment`, `Exec`, `Icon`, `Categories`,
  `Terminal`, `StartupNotify`.

## Своя база зависимостей

Создайте `~/.config/kuznica/mappings.json`:

```json
{
  "packages": {
    "libmylib2": "mylib",
    "obsolete-package": ""
  },
  "ignored": ["some-debian-only-package"]
}
```

Пустое значение и список `ignored` означают, что зависимость отбрасывается.
Пользовательские правила переопределяют встроенные.

## Типичные проблемы

| Сообщение | Что делать |
| --- | --- |
| `makepkg is not installed` | `sudo pacman -S base-devel` |
| `pacman is not installed` | программа запущена не в Arch Linux |
| `not enough free disk space` | освободите место в каталоге сборки |
| `neither pkexec nor sudo is available` | установите `polkit` или `sudo` |
| `archive member escapes the extraction directory` | пакет повреждён или вредоносен |
| `desktop-file-validate is not installed` | `sudo pacman -S desktop-file-utils` |
