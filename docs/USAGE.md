# Руководство пользователя

## Запуск

```bash
kuznica                 # обычный запуск
kuznica program.deb     # сразу открыть пакет
kuznica -version        # версия
```

## Главное окно

| Элемент | Назначение |
| --- | --- |
| Меню «Файл» | открыть пакет, выход |
| Меню «Правка» | копировать журнал в буфер, очистить журнал |
| Меню «Настройки» | параметры программы |
| Меню «Справка» | «О программе» |
| Зона Drag & Drop | перетащите сюда `.deb` |
| Вкладка «Информация» | название, версия, архитектура, описание, размер, лицензия, автор, сайт, конфликты, рекомендации, число контрольных сумм |
| Вкладка «Зависимости» | список `Debian → Arch` |
| Вкладка «Файлы» | содержимое `data.tar` |
| Вкладка «Журнал» | все действия и ошибки |
| Кнопки | Конвертировать, Создать пакет, Установить, Игровой режим, Открыть папку, Просмотреть журнал |

## Настройки

**Общие**

* Тема: системная, светлая, тёмная.
* Язык: русский, английский (интерфейс перестраивается сразу).
* Каталог сборки (по умолчанию `~/kuznica`).

**Работа**

* Использовать `makepkg` — если выключено (или `makepkg`/`fakeroot` нет в системе), пакет собирает встроенный упаковщик.
* Удалять временные файлы.
* Автоматически устанавливать зависимости (`pacman -S --needed`).
* Создавать `.desktop`.
* Проверять `.desktop` через `desktop-file-validate`.
* Искать иконки автоматически.
* Показывать журнал после сборки.

**SteamOS**

* Адаптировать для игрового режима SteamOS — включено по умолчанию, если
  программа запущена на SteamOS (`ID=steamos` в `/etc/os-release`). После
  сборки пакета КУЗНИЦА сразу выполняет адаптацию (см. ниже); кнопкой
  «Игровой режим» её можно запустить вручную в любой момент после конвертации.

Настройки хранятся в `~/.config/kuznica/config.json`.

## Игровой режим SteamOS

В игровом режиме (сессия gamescope) нет ни файлового менеджера, ни меню
приложений: запускать можно только то, что есть в библиотеке Steam. Плюс
корень SteamOS смонтирован только для чтения и полностью перезаписывается при
обновлении системы, поэтому `pacman -U` там либо не работает, либо результат
исчезает после апдейта.

Кнопка «Игровой режим» решает это без прав root:

1. содержимое пакета копируется в `~/Applications/<пакет>` — раздел `/home`
   записываемый и обновление SteamOS его не трогает;
2. создаётся скрипт `~/Applications/<пакет>/kuznica-launch.sh`, который
   подставляет префикс в `PATH`, `LD_LIBRARY_PATH`, `XDG_DATA_DIRS` и
   `GSETTINGS_SCHEMA_DIR`, — так программа из Debian находит свои библиотеки и
   данные вне `/usr`;
3. скрипт добавляется во все профили Steam как сторонняя игра
   (`~/.steam/steam/userdata/<id>/config/shortcuts.vdf`, поддерживаются также
   `~/.local/share/Steam` и Flatpak-Steam). Прежний файл сохраняется рядом как
   `shortcuts.vdf.kuznica.bak`, существующие ярлыки не теряются, повторная
   адаптация обновляет запись, а не создаёт дубль;
4. иконка берётся из пакета, ярлык помечается тегом `KUZNICA`;
5. дополнительно создаётся `~/.local/share/applications/kuznica-<пакет>.desktop`
   для режима рабочего стола.

После адаптации: **перезапустите Steam** (он перезаписывает `shortcuts.vdf` при
выходе), перейдите в игровой режим и откройте «Библиотека» → «Не Steam».

Ограничения: программы, которые жёстко прописывают пути `/usr/...` внутри
своего кода, могут не найти данные в префиксе; библиотеки самой системы
(например `libgtk-3`) должны быть в SteamOS или в пакете.

## Файл .desktop

После конвертации, если включена настройка «Создавать .desktop»:

* если пакет уже содержит `.desktop`, программа спросит — использовать
  существующий, заменить, создать новый или открыть редактор;
* иначе создаётся новый файл: исполняемый файл ищется в `usr/bin`, `usr/sbin`,
  `opt`, иконка — в `usr/share/icons` и `usr/share/pixmaps`, категория
  выводится из секции Debian (`devel` → `Development;`, `games` → `Game;` …);
* в редакторе можно изменить `Name`, `Comment`, `Exec`, `Icon`, `Categories`,
  `Terminal`, `StartupNotify`.

## Своя база зависимостей

Создайте `~/.config/kuznica/mappings.json`:

```json
{
  "packages": {
    "libmylib2": "mylib",
    "obsolete-package": ""
  },
  "ignored": ["some-debian-only-package"]
}
```

Пустое значение и список `ignored` означают, что зависимость отбрасывается.
Пользовательские правила переопределяют встроенные.

## Типичные проблемы

| Сообщение | Что делать |
| --- | --- |
| `makepkg is not installed` | ничего: сборка переключится на встроенный упаковщик, либо `sudo pacman -S --needed base-devel` |
| `Cannot find the fakeroot binary` | то же самое: `fakeroot` нужен только для `makepkg` |
| `read-only filesystem` (SteamOS) | используйте кнопку «Игровой режим» (без root) либо `sudo steamos-readonly disable`, затем `sudo pacman -U …` |
| `Steam не найден` | запустите Steam хотя бы один раз, чтобы появился профиль в `userdata` |
| ярлык не появился в игровом режиме | Steam перезаписывает `shortcuts.vdf` при выходе: закройте Steam, повторите адаптацию, затем запустите Steam |
| `unable to satisfy dependency 'X'` | зависимость есть в PKGBUILD, но не в репозиториях: добавьте соответствие в `~/.config/kuznica/mappings.json` (пустое значение отбросит её) |
| `pacman is not installed` | программа запущена не в Arch Linux |
| `not enough free disk space` | освободите место в каталоге сборки |
| `neither pkexec nor sudo is available` | установите `polkit` или `sudo` |
| `archive member escapes the extraction directory` | пакет повреждён или вредоносен |
| `desktop-file-validate is not installed` | `sudo pacman -S desktop-file-utils` |
